Phone numbers Saved ✓








111-1111Always directs to DCNow! for compatibility with openMenu and standard ISP configs (fixed).

When "Auto reset" is enabled, dialing it also resets the network to the default network.


Any otherConnects to the currently selected network.

Set your Dreamcast ISP config to any 7-digit number to use this feature.






A number can be a whole number or just its ending: it counts when what the Dreamcast dials ends with it, so prefixes from the ISP config don't matter and the longest match wins. Use digits, * and # (3 to 24 characters), for example *61#. Hang-up numbers select the network, then get a busy tone instead of an answer.

Wi-Fi setupWhich push button, or both, held 3 s starts it
  




LED count, output pin and wire order (most WS2812 strips are GRB) take effect within a second; switching the LED output pin to GPIO10 only works if SPI was enabled when installing (sudo ./install.sh --led-gpio=10, needs a reboot). Button pin and function changes take effect within a couple of seconds - pick two different pins for the two buttons. A push button's function (Off, Toggle network, Select DCNow!, Select DCNET) fires on a short press; a toggle switch (wired between the pin and GND, on = closed) sets the network, or starts and ends Wi-Fi setup, by its position - also when the Pi starts.

Brightness




White balance: tap Preview on LED to show solid white, then turn down whichever of R, G or B looks too strong until it looks neutral - leave the others at 255. Tap Preview again when done. This corrects every colour the LEDs show, not just white, and takes about 30 seconds. Brightness is the maximum for the whole strip, applied after the correction (logarithmic: the left half is the low range that suits an indicator LED).


Status LED Saved ✓



 

 
MessageColourEffectLevel






The tabs choose which selected network the table is for. Tick a message to use it; the LED is off when no ticked message applies. Errors always have higher priority than information. Effect: tap to pick solid, blink, breathe, RGB or (with a strip) an animation, its speed, and with a strip which LEDs it uses (later messages in the list draw underneath earlier ones). Level: its own brightness; grey means the maximum brightness above. The status dot on the main page previews the most important message.

How to update by hand
 
This add-on (a newer version is found on GitHub; your settings are kept):

 
  1. Open a terminal on the Pi (SSH).
  2. cd DreamPiAutoToggle
  3. git pull
  4. sudo ./install.sh (add the same options you used before, such as --wifi or --leds=30)

 
DreamPi itself updates its own scripts when the Pi starts and has internet. Restart the Pi (sudo reboot) to get a newer version. If /boot/noautoupdates.txt exists, DreamPi does not update itself: remove that file first.
