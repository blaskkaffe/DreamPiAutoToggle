Phone numbers Saved ✓








111-1111Always directs to DCNow! for compatibility with openMenu and standard ISP configs (fixed).

When "Auto reset" is enabled, dialing it also resets the network to the default network.


Any otherConnects to the currently selected network.

Set your Dreamcast ISP config to any 7-digit number to use this feature.






A number can be a whole number or just its ending: it counts when what the Dreamcast dials ends with it, so prefixes from the ISP config don't matter and the longest match wins. Use digits, * and # (3 to 24 characters), for example *61#. Hang-up numbers select the network, then get a busy tone instead of an answer.

Update the add-on
  

 




The DreamPi script versions are the dates DreamPi's own auto-update compares.


How to update by hand
 
This add-on (a newer version is found on GitHub; your settings are kept):

 
  1. Open a terminal on the Pi (SSH).
  2. cd DreamPiAutoToggle
  3. git pull
  4. sudo ./install.sh (add the same options you used before, such as --wifi or --leds=30)

 
DreamPi itself updates its own scripts when the Pi starts and has internet. Restart the Pi (sudo reboot) to get a newer version. If /boot/noautoupdates.txt exists, DreamPi does not update itself: remove that file first.







 
Reboot DreamPiRestarts the Raspberry Pi; it is back in about a minute. A call in progress is cut.
